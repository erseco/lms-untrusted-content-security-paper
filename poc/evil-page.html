POC-SAFE — Página HTML de Moodle

Este es el artefacto canónico para el recurso Página. La sonda mide capacidades sin exfiltrar datos ni modificar el anfitrión.

Laboratorio desechable: las acciones de Moodle que aparecen más abajo sí realizan cambios reales, pero únicamente después de pulsar Ejecutar. El nombre y la foto se restauran desde el perfil; los cursos POC-… se eliminan desde Administración.

Resultado de la sonda

⚠ LA SONDA NO SE EJECUTÓ AQUÍ

No hay medición que mostrar. Esto es en sí un resultado: o el navegador tiene JavaScript desactivado, o la política de contenidos del anfitrión bloqueó el script, o el script falló antes de terminar.

—

—

La comprobación se hace sola al cargar la página y no modifica nada: solo pregunta al navegador qué le permitiría hacer este contenido. Los valores de sesión nunca se muestran, ni siquiera parcialmente: esta tabla dice si una capacidad estuvo presente y, cuando aplica, su longitud o su recuento, nunca el dato en sí. Pulsa ⓘ en cada fila para ver qué mide, qué implica y de qué protege el aislamiento.

ACCESO AL ANFITRIÓN — alcanzarlas es alcanzar la sesión de quien abre el recurso
Conservar acceso de mismo origen al documento que lo contiene.
—
—
Propiedad comprobada
sandboxAllowsSameOrigin (derivado)
Qué mide
Si este material y la página de la plataforma se tratan como el mismo sitio. Cuando es así, el navegador deja de separarlos.
Qué implica
«Bloqueado» es lo deseable. «Alcanzado» indica que el iframe no está sandboxed de verdad, o que se le concedió allow-same-origin.
De qué protege el aislamiento
Si aquí hay aislamiento, el resto de lecturas al anfitrión no deberían funcionar. Si no lo hay, casi todo lo demás queda al alcance.

—
—
Propiedad comprobada
window.API_1484_11 · window.API
Qué mide
Si la API SCORM del curso está al alcance. La sonda no llama a ningún método: solo detecta si el objeto existe.
Qué implica
«Disponible» no es un fallo por sí solo: el contenido SCORM legítimo la necesita. Solo es peligrosa si además hay acceso al anfitrión.
De qué protege el aislamiento
El aislamiento debe dejar usable esta API (por ejemplo vía postMessage) sin abrir el DOM del LMS.

Acciones de demostración para Moodle

Ninguna acción se ejecuta automáticamente. Solo funcionan con una sesión autorizada y permisos suficientes en un Moodle local same-origin.

Vitrina visual de impacto

Estos tres efectos solo modifican temporalmente el DOM local después de pulsar Ejecutar: no hacen peticiones de red ni persisten cambios. El inicio de sesión es una simulación y no captura, almacena ni transmite lo escrito.
